# Data-transformation-modeling

## 📌 Overview

This project focuses on transforming raw data into a structured, analysis-ready format and building a reliable data model for reporting and dashboard development.

The objective was to improve data structure, establish relationships, and create meaningful calculations for business insights.

## 🔄 Data Transformation Steps

* Cleaned and standardized column names
* Converted incorrect data types (Text → Number/Date)
* Split and merged columns where required
* Grouped and aggregated data
* Removed duplicates and null values
* Created calculated columns

## 🧩 Data Modeling Process

* Built relationships between fact and dimension tables
* Established primary and foreign key connections
* Ensured active relationships in Model View
* Created DAX measures for KPIs
* Optimized model for performance and accuracy

## 📊 Key Features Implemented

* Calculated Columns
* Measures using DAX
* Aggregations & Grouping
* Relationship Management
* Optimized Data Model Design

## 📈 Outcome

* Structured, analysis-ready dataset
* Improved reporting accuracy
* Efficient and scalable Power BI dashboard foundation
